# MaxZ Blog

## 这是什么？

这是一个基于Minima的个人博客，基于[mxkkkk的模板制作](https://www.zhihu.com/question/19759810/answer/2072421258734613705)

![](/assets/view_dark.png)

## 亮点

* 有Liquid Glass的UI支持
* UI可以在Liquid Glass模式、高斯模糊和纯色模式之间自由切换
* 卡片式布局
* 文章页面使用Fluent风格
* 支持LaTex公式的$$或者$$ $$格式
* 支持深色模式和浅色模式切换（PC 顶栏点调色盘图标；手机端点汉堡菜单里的「设置」）
* 支持三级密级文章：`secret: 1` 从所有列表消失但可被搜索到；`secret: 2` 默认搜不到，且只能通过限时分享链接访问
* 文章里可以放音频：自定义播放器显示文件名（自动去掉扩展名），播放时顶栏胶囊会像 iOS 灵动岛那样显示歌名和进度条
* 背景音乐：顶栏 ♪ 点开曲目列表自选，顺序循环播放；往 `music/` 里丢文件就自动上线，不用改配置

## 私密文章怎么用

在文章 frontmatter 里加 `secret: 1` 或 `secret: 2`（不写即公开）：

| `secret` | 首页/列表/标签页 | 站内搜索 | 访问方式 |
|---|---|---|---|
| 不写 / `0` | 显示 | 可搜到 | 永久链接 |
| `1` | 隐藏 | 可搜到 | 永久链接 |
| `2` | 隐藏 | 默认搜不到，加 `?secret=1` 或按 `Ctrl/Cmd + Shift + .` 后才可搜到 | 仅限时分享链接 |

### 别人怎么看

2 级文章页有一个「分享」按钮，可选 1 小时 / 2 小时 / 1 天 / 3 天 / 7 天 / 15 天，
生成的链接形如 `<文章地址>#token=xxx`。对方打开时 token 会被校验并立即从地址栏清除，
转存到 sessionStorage（刷新仍可访问，关掉标签页失效）；校验失败会跳到一个随机路径，
渲染站点真实的 404 页。

### 作者自己怎么看（重要）

分享按钮长在文章页里，而文章页本身要令牌才打得开——所以**作者发布后拿不到第一条令牌**。
为此有一个自举入口：口令授权。

#### 第一次：授权（每台设备只需一次）

在文章地址**末尾加上 `?author=1`**：

```
https://maixzzh.github.io/2026/09/26/test/?author=1
```

会弹出「这篇是私密文章」的口令框，输入作者口令回车。页面立刻变成正文，
地址栏里的 `?author=1` 会被自动抹掉。

口令正确后会签发一枚 10 年有效、**通配所有二级文章**的令牌存进 localStorage。

#### 之后：正常访问就行

授权过的设备，直接开普通地址就能看：

```
https://maixzzh.github.io/2026/09/26/test/
```

也可以走站内搜索——按 `Ctrl/Cmd + Shift + .` 解锁搜索、搜标题、点结果直接进。
（搜索解锁只影响"能不能搜到"，阅读权限仍然靠令牌；所以**在别人的设备上，
搜索结果里的二级文章链接仍然是 404**，他们必须走分享链接。）

#### 文章地址怎么推

文件名去掉日期前缀就是 URL 末段，**月份一定补零**：

| 文件 | URL |
|---|---|
| `_posts/2026-9-26-test.md` | `/2026/09/26/test/` |
| `_posts/2026-11-3-随笔.md` | `/2026/11/03/随笔/` |
| `_posts/2026-09-19-cspyj.md` | `/2026/09/19/cspyj/` |

注意第二行：文件名写的是 `9-26`（月份没补零），URL 里是 `09/26`——由 Jekyll 的 `%m` 格式决定。

#### 四个容易踩的点

1. **换设备 / 换浏览器 / 清了浏览器数据** → 回到第一步重新授权一次。
2. **本地预览是另一套**。`bundle exec jekyll serve` 的域名是 `localhost:4000`，
   浏览器视为完全不同的网站、localStorage 不共享，所以要单独走一次
   `http://localhost:4000/2026/09/26/test/?author=1`。
3. **忘记口令不会被锁在外面**。源码里只存哈希、没有明文，但可以随时重设：
   ```bash
   node tools/authorhash.js '新口令'
   ```
   把输出的 16 位十六进制填进 `assets/js/secret.js` 的 `PHRASE_HASH`。推送后
   用旧口令授权的设备会失效，需要重新输一次。
   > 初始口令**不写在本文件里**（这里的仓库是公开的，写了等于公开）。
   > 如果你不确定当前口令，直接用上面的命令设一个新口令即可。
4. **`secret: 1` 的文章不需要这一套**。它们从列表消失，但永久链接直接能打开，
   既不需要口令也不需要分享链接。只有 `secret: 2` 才有门禁。

#### 分享给别人时

**不用给别人口令**——`?author=1` 那条路是给作者自己的。给别人就用文章页里的
「分享」按钮选有效期，把生成的那条 `#token=xxx` 链接发过去。对方不需要任何授权，
但链接过期就失效。

> 不带 `?author=1` 时行为不变：没有有效令牌一律跳到真 404，
> 所以普通访客看到的和打错网址完全一样。

> ⚠️ **这是「防君子不防小人」的方案，不是访问控制。** 静态站点没有服务端鉴权，
> 文章正文仍在页面 HTML 里、`_posts/*.md` 源码在公开仓库里、`search-secret.json`
> 也可直接下载；作者口令的校验也在前端，会读 JS 的人可以绕过。它能做到的是：
> 从所有列表和公开索引里彻底移除、让默认搜索碰不到、抑制搜索引擎收录、
> 让随手翻到变得不可能——但挡不住存心要看的人。
>
> 另：拿到分享链接的人能看到「分享」按钮，也就是可以再转发。这是有意的
> （方便对方转发给同一批人），如果不想这样，把 `_layouts/post.html` 里
> 分享按钮的渲染条件从 `page.secret == 2` 改成「仅作者令牌存在时才注入」。

## 怎么在文章里放音频

直接在正文里写 HTML，**独立成行、不要缩进**：

```html
<audio controls preload="metadata" data-title="秋日私语"
       src="{{ '/assets/audio/qiuri-siyu.mp3' | relative_url }}"></audio>
```

会被自动替换成站点风格的播放器，标题显示**文件名（去掉扩展名）**。
播放时顶栏胶囊中间让出位置显示 `♪ 歌名 ▶ ━━━`（两侧的头像 / 搜索 / 设置图标保留），
滚动不收缩、暂停也保留，**播完才收起**。手机锁屏和通知栏也能控制播放。

| 属性 | 说明 |
|---|---|
| `controls` | **必须写**。它是浏览器禁用了 JS 时唯一的降级路径 |
| `data-title` | 可选。文件名不好看时用它覆盖显示名（如「秋日私语 - 钢琴版」） |
| `preload="metadata"` | 建议写。不写会被自动补上；别写 `auto`，会抢带宽 |
| `data-keep-native` | 可选。加上就跳过替换、保留浏览器原生控件 |

音频文件放 `assets/audio/`，引用走 `relative_url`，这样改了 `baseurl` 也不会失效。

### 三个坑

1. **别缩进**。行首 4 个及以上空格会被 Markdown 当成代码块，把标签原样显示出来；
   也别缩进着塞进列表项里。
2. **文件名本身带点号没关系**。`某某 - Live 版.ver2.mp3` 只会去掉 `.mp3`，
   不会把 `.ver2` 一起削掉。
3. **多个音频自动互斥**。播放新的会自动暂停旧的，不会两个一起响。

> **不会自动播放。** 不是没实现——浏览器规定必须有用户交互才出声，写了 `autoplay`
> 通常也会被拦下来。想让人听到，就得让人自己点。

## 背景音乐

顶栏搜索图标左边的 ♪ 点开曲目列表，选一首就开始播放，**顺序播完整张列表后回到第一首**。
播放信息显示在顶栏胶囊（灵动岛）中间：`♪ 歌名 ▶ ━━━ ✕` —— 右侧的 ✕ 是停止（暂停并归零）。
背景音乐播放时滚动页面，胶囊照常收缩成一个图标，不会一直挡着正文。

### 加歌

把音频丢进 `music/` 就行，**不用改任何配置**——清单是构建期扫目录生成的
（`music.json`，与 `search.json` 同一套机制）。

```
music/
  起风了.mp3              ← 根目录这组显示为「单曲收藏」，排在列表最前
  Flower Dance.mp3
  2026年4月4日/           ← 子目录自成一组，组名就是目录名
    III.mp3
    Big Big World.mp3
```

| 规则 | 说明 |
|---|---|
| 歌名 | **文件名去掉扩展名**（`某某 - Live 版.ver2.mp3` 只削掉 `.mp3`，不会削掉 `.ver2`） |
| 格式 | `.mp3` `.m4a` `.m4b` `.aac` `.ogg` `.oga` `.opus` `.wav` `.flac` `.weba` `.mp4` |
| 封面 | 目录里混着的 jpg 会被自动滤掉，不会当成曲目 |
| **必须进仓库** | 清单是**构建期扫盘**生成的，没提交 `music/` 线上就是空列表 |

### 两个限制

1. **离开本页会停止播放**。静态站点每次点链接都是整页重载，音乐必然中断。
   要做跨页续播得上 SPA，成本远超收益，还会和现有的几个状态机打架——所以不做。
2. **不会自动播放**。浏览器规定必须有用户交互才出声，得自己点一下。
