# MaxZ Blog

## 这是什么？

这是一个基于Minima的个人博客，基于[mxkkkk的模板制作](https://www.zhihu.com/question/19759810/answer/2072421258734613705)

![](/assets/view_dark.png)

## 亮点

* 有Liquid Glass的UI支持
* UI可以在Liquid Glass模式、高斯模糊和纯色模式之间自由切换
* 卡片式布局
* 文章页面使用Fluent风格
* 支持LaTex公式的$$或者$$ $$格式
* 支持深色模式和浅色模式切换（PC可以自由切换，手机端需要横屏模式，目前正在修复该问题）

## 如何使用

* 访问本project的GitHub Repo：[https://github.com/maixzzh/maixzzh.github.io](https://github.com/maixzzh/maixzzh.github.io)
* 然后将该项目的名称重命名为(YourUserName).github.io
