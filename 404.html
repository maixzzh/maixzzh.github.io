你要找的页面不在这里。

可能是链接打错了，或者这个地址已经失效。回到 首页 看看吧。

{% comment %} 这个文件同时承担两个职责： 1. GitHub Pages 对未命中的路径会用它响应，并带**真实的 404 状态码** （本地 jekyll serve 同理）。这是本站唯一能产生真 404 的地方。 2. 私密文章的门禁校验失败时，assets/js/secret.js 会 location.replace 到 一个随机的不存在路径，从而落到这里。这样「假 404」和「真 404」在 地址栏、状态码、页面外观上完全一致，无法区分，也就不必再维护 第二套 404 标记。 注意：直接访问 /404.html 会得到 HTTP 200（文件确实存在），这是静态托管的 固有行为，没法避免。 {% endcomment %}
